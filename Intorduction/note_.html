Introduction to Tensors

In PyTorch, a Tensor is the fundamental building block. It is a multi-dimensional array similar to a NumPy array, but with two key superpowers:

  • It can run on a GPU (Graphics Processing Unit) for faster computation.
  • It supports Automatic Differentiation (Autograd) for building neural networks.
Tensors are used to encode the inputs and outputs of a model, as well as the model’s parameters.

Creating Tensors

PyTorch offers several ways to initialize tensors depending on your data source.

1. From Data

You can create a tensor directly from a Python list.

import torch

# Create a scalar
scalar = torch.tensor(7)

# Create a vector
vector = torch.tensor([1, 2, 3])

# Create a matrix
matrix = torch.tensor([[1, 2], [3, 4]])

2. Zeros and Ones

Useful for initializing weights or masks.

# 3x4 matrix of zeros
zeros = torch.zeros(size=(3, 4))

# 3x4 matrix of ones
ones = torch.ones(size=(3, 4))

3. Range of Numbers

Do not use torch.range() as it is deprecated. Use torch.arange() instead. 
# Create a range from 0 to 10
one_to_ten = torch.arange(start=1, end=11, step=1)

Random Tensors

Random tensors are critical because this is how Neural Networks learn. We initialize them with random numbers and adjust those numbers as the network sees data.

Start with random numbers -> Look at data -> Update random numbers -> Repeat 
# Create a random tensor of size (3, 4)

Data Types (dtypes)

Data types specify how the data is stored in memory. The default in PyTorch is float32.

Common Types

  • torch.float32 or torch.float: 32-bit floating point (Standard).
  • torch.float16 or torch.half: 16-bit floating point (Used for mixed precision/faster training).
  • torch.int64 or torch.long: 64-bit integer (Used for indices).
Tip: Tensor operations usually fail if tensors are on different devices (CPU vs GPU) or have different data types (float32 vs float16).

Tensor Operations

PyTorch supports standard mathematical operations similar to NumPy.

Matrix Multiplication

One of the most common operations in deep learning. The inner dimensions must match.

(3, 2) @ (2, 3) -> (3, 3)

tensor = torch.tensor([1, 2, 3])

# Element-wise addition
print(tensor + 10) 

# Element-wise multiplication
print(tensor * 10)

# Matrix Multiplication (Dot Product)
value = torch.matmul(tensor, tensor)

GPU Acceleration

Deep learning models require massive parallel computation. GPUs are designed exactly for this. We can move tensors to the GPU using the .to() method.

Check for GPU

import torch
print(torch.cuda.is_available())

Device Agnostic Code

Write code that runs on GPU if available, else CPU.

device = "cuda" if torch.cuda.is_available() else "cpu"

tensor = torch.tensor([1, 2, 3])

# Move tensor to device
tensor_on_gpu = tensor.to(device)

Autograd Basics

torch.autograd is PyTorch’s automatic differentiation engine that powers neural network training.

When you set requires_grad=True on a tensor, PyTorch tracks all operations on it to calculate gradients later.
