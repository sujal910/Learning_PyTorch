Introduction to Tensors

Tensors are the multi-dimensional arrays that power neural networks. In PyTorch, they are optimized for Automatic Differentiation and Hardware Acceleration (GPU/TPU).

1. The Geometry of Data

Scalar (0-D): A single number. ndim = 0.

Vector (1-D): A list of numbers. ndim = 1. Often used for bias terms.

Matrix (2-D): Rows and Columns. ndim = 2. Standard for weight matrices.

Tensor (n-D): Multi-dimensional arrays. Used for Images [C, H, W] or Video [F, C, H, W].

2. Tensor Creation & Attributes

When you create a tensor, three attributes determine if your code will run or crash:

Dtype The precision of numbers (e.g., float32, int64).
Device Where it is stored (CPU vs CUDA).
Shape The dimensions (Size) of the data. 
import torch

# The proper way to initialize a 4D Tensor (Common in CV)
TENSOR = torch.tensor([[[[1, 2, 3],
                         [7, 8, 9],
                         [8, 9, 5]]]])

print(f"Dimensions: {TENSOR.ndim}")
print(f"Shape: {TENSOR.shape}") # torch.Size([1, 1, 3, 3])
💡
Pro Tip: Use .ndim to find the number of dimensions and .shape to see the specific size of those dimensions.

3. Initializing Tensors

In Deep Learning, we rarely write data by hand. We use helper functions:

Function Result Typical Use Case
torch.rand(3, 4) Random numbers [0, 1) Initializing model weights
torch.zeros(10) Fill with 0.0 Masking or padding
torch.arange(0, 10) Range 0 to 9 Creating index lists
torch.zeros_like(x) Zeros with x's shape Keeping consistency between layers

4. Data Types (Precision vs Performance)

PyTorch defaults to Float32. However, using Float16 can make models 2x faster on modern GPUs (Half-precision training).

⚠️
Common Mistake: torch.range() is deprecated! Always use torch.arange() to avoid endpoint confusion and warnings.

5. The "Big Three" Troubleshooting Checklist

If your PyTorch code crashes, it is almost certainly one of these three things:

  1. Shape Mismatch: You are trying to multiply a [3x2] matrix by a [5x2].
  2. Device Mismatch: One tensor is on the CPU and the other is on the GPU.
  3. Dtype Mismatch: You are trying to add a LongTensor to a FloatTensor.
# Fixing a type mismatch
x = torch.tensor([1, 2, 3]) # int64
y = x.type(torch.float32)   # Now float32
print(y.dtype)
